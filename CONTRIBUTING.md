# Contributing

Thanks for helping improve Agent Dashboard.

## Development

1. Fork and clone the repository.
2. Run `npm install`.
3. Make focused changes in `src/` or `styles.css`.
4. Run `npm run build` and `npm run lint`.
5. Open a pull request that explains the behavior change and how it was tested.

Please do not include API keys, tokens, private Vault content, or local filesystem paths in issues or pull requests.

## Bug reports

Include the Obsidian version, operating system, reproduction steps, expected behavior, and any relevant error message. Remove private note content before attaching logs or screenshots.
